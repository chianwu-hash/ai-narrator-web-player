# Gemini Notebook 工作室介面探查與更名修復

日期：2026-10-04

## 問題與直接原因

正式製書《如何造就一個好老師》七集已生成，其中三列顯示相同 EP01 名稱，但時長不同。暫停當時的製書子程序後，以各列「查看提示詞和來源」確認七集識別碼各自仍是 EP01–EP07；來源數均為 3，內容檔案沒有被覆蓋。

新版工作室音訊圖示為 `audio_spark`，整列 innerText 另含「未讀／已讀」、播放、更多等文字。舊 `_parse_tile_title` 只排除 `audio_magic_eraser`，導致正確更名也被判定為標題不符。更名會讓列重新排序，而重試路徑在找不到原列時沿用舊 index，故將其他音訊也改成 EP01。底層更名的成功檢查又只看整個 studio-panel 是否包含名稱，無法證明是原音訊儲存成功。

## 後續操作原則

1. 可見名稱不能當成內容身分的唯一真相；有衝突先讀提示詞並核對 artifact id。
2. 成功判定必須針對同一個 artifact；列表中的另一列出現目標名稱不能算成功。
3. ID 缺失、提示詞不明、重複、來源不符或原列消失時停止，不刪除或重生猜測中的音訊。
4. 外部 UI 仍可能改變；更名驗收通過不等同所有功能都已驗收。下載／後製／交付完成以正式任務狀態為準。
